# 조건을 읽는 자체 소형 결정 모델: 첫 학습

2026-10-10. Gooo가 선언한 선택 조합에 점수를 주는 모델을 Go로 학습했습니다.
새로 만든 소스·한영 의도·조건 관측 입력을 사용합니다. 학습·판단 구현의 소스는
`db691ac8f302b2913aebc30fefb2202a029b4668`이며, 해당 깨끗한 소스로 빌드한 실행 파일을
한 번 사용했습니다. 원래 모델과 가중치는 `result/`에 보관합니다.

## 어떻게 만들었나

먼저 Gooo 소스24개를 작성했습니다. 절댓값 출력을 유지하면서 중간 비교 조건을
음수·양수로 바꾼 짝을 만들었습니다. 컴파일러
`3ff6dec5cbd91e050439bce6e695cde890eb3d5b`가 각 소스를 typed plan으로 읽었습니다.
이 소스는 실험 당시 PR1440 후보입니다.

각 프로그램의 네 선택 조합을 컴파일하고, 선언된 출력7개와 조건3개를 검사했습니다.
모두 맞는 조합들이 학습의 정답 집합입니다. 실제 학습에는8개 프로그램에서 만든40개
입력만 전달했습니다. 처음 보는 표현, 지역 변수 추가 구조, 둘을 함께 바꾼 자료는
별도로 평가했습니다. 각 프로그램에 첫 판단1개와 네 후보의 조건 관측 입력4개가 있습니다.
조건을 모두 만족한 관측은 실패 입력이 비어 있으므로 첫 판단과 같은 정보가 될 수 있습니다.

모델의 선택 직후 해당 조합을 Gooo·Go 본문으로 만들고 typed interpreter로 다시 실행했습니다.
120개 선택의 본문과 출력·조건 성적을 기록했습니다. 이번 명령에서 native 실행 파일을
빌드하거나 실행한 횟수는0입니다.

## 결과

아래 정답은 출력7개와 중간 조건3개를 모두 만족한 **후보 조합**입니다.

| 자료 | 첫 판단 | 조건 관측 뒤 판단 | 고정0번 후보 기준 |
| --- | ---: | ---: | ---: |
| 학습에 사용한8개 프로그램 |8/8|32/32|4/8,16/32|
| 같은 구조의 새로운 한영 표현 |2/4|12/16|2/4,8/16|
| 지역 변수를 추가한 구조 |8/8|32/32|4/8,16/32|
| 새 표현과 지역 변수 구조 함께 |2/4|12/16|2/4,8/16|

지역 변수 자료도 같은 절댓값 문제입니다. 관측 입력 여러 개는 같은 소스를 공유합니다.
이 수치를 서로 독립적인 문제120개나 일반 언어 정확도로 해석하기는 어렵습니다.

새 표현의 양수 조건에서12개 판단이 실패했습니다. 그중9개는 출력7/7인데 조건1/3인
조합을 골랐습니다. 나머지3개는 출력1/7·조건1/3입니다. 최종 출력과 중간 조건을
따로 측정해야 드러나는 차이입니다. 평가 후 학습 설정이나 가중치를 수정하지 않았습니다.

## 읽기와 재집계

```sh
cd studies/condition-candidate-20261010
shasum -a 256 -c SHA256SUMS
cd ../..
GOWORK=off GOTOOLCHAIN=go1.27.2 go run ./studies/condition-candidate-20261010 \
  studies/condition-candidate-20261010
```

이 명령은 원본120행 재집계와 파일 해시·모델 형식만 확인합니다. 새 학습·모델 판단·
프로그램 실행은0회입니다. 새 실험은 [모델 사용 안내](../../conditiondecision/README.md)의
`condition-fit` 명령으로 새 출력 폴더에 만들 수 있습니다.

`protocol.txt`는 학습 전에 고정한 구성입니다. `dataset.json`은 원래 Gooo 문장·정확한
정수 사례·소스 해시·컴파일러가 내보낸 계획을 함께 담습니다. `exporter/`는 형제 폴더의
컴파일러 체크아웃을 사용해 그 자료를 새로 내보내는 Go 모듈입니다.

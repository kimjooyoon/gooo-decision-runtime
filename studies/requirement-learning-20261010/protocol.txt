Fresh requirement-conditioned decision study, frozen before training.

Question: can source/output/condition inputs distinguish correct internal paths
when two Gooo contracts share the same output examples? Does a trained compact
model use that information on held-out source variants, and does Gooo preserve
finite-case completeness when the first prediction is wrong?

172 authored Gooo documents, each with two binary source choices (comparison
operand order and branch layout), eight exact int64 output cases and four
complete candidate masks. Adjacent condition-goal pairs share output goals,
source features and output features; their declared comparison results differ.
The two comparison forms agree (false) at equality. Every output template has
equal arm values at equality, so both internal paths can implement each output
goal. Output goals and intermediate-condition goals vary independently.

Predeclared cohorts: train32, unseen constants32, representation48, wording32,
unseen negative-bound family8, reordered source choices8, rare128th condition4,
empty condition suite4, contradictory conditions4. Thus136 satisfiable held-out
documents plus32 training documents and4 unsatisfiable held-out documents.
The rare cohort has127 unique nonnegative inputs mapped to the comparison's
equality value by a fixed source prefix, and one decisive negative tail input.
Its eight output examples are negative; the nonnegative conditions exercise the
fixed-prefix equality region without adding output promises in that region.
This is a stress cohort with an extra fixed branch, not an isolated row-order
ablation. Contradictions require the same Boolean result at distinct inputs
below and above the threshold, impossible for either source comparison.
Representations are local aliases, assignments and rebinding. Wording cohorts
use English and a fresh Korean phrasing. Training is Korean. All arithmetic and
source examples preserve int64, including values beyond2^53. Bounds avoid int64
overflow. This is a related-template corpus, not a general language benchmark.

Lower every frozen source and check declared rows before fitting. Enumerate all
four Gooo candidates to obtain acceptable sets before either model fit. Keep

for the old two-channel and new three-channel models; omit the four impossible
contracts from input-information bounds and retain their search results.

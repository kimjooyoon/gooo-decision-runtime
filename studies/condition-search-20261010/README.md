# 자체 모델을 Gooo 경로 탐색에 연결하기

2026-10-10. 앞서 학습해 공개한 6,218개 매개변수 모델을 실제 경로 탐색에 연결했습니다.
가중치는 그대로 두고 같은 Gooo 소스 24개를 세 방식으로 실행했습니다. 소스에 선언된
출력 7개와 중간 조건 3개를 모두 만족할 때 탐색을 마칩니다. 한 소스마다 선택 조합은
4개이며, 최대 4번까지 시도했습니다.

| 방식 | 사례를 모두 만족한 소스 | 시도한 경로 합계 | 실제 모델 호출 |
| --- | ---: | ---: | ---: |
| 선언된 기본 경로부터 탐색 | 24/24 | 60 | 0 |
| 모델의 첫 판단으로 탐색 순서 결정 | 24/24 | 35 | 24 |
| 실패한 조건을 모델에 전달해 순서 변경 | 24/24 | 28 | 28 |

피드백 방식에서는 첫 후보 20개가 바로 통과했습니다. 나머지 4개는 중간 조건에서
실패했고, 그 관측을 전달한 다음 후보가 통과했습니다. 28번 가운데 추가 판단은 4번입니다.
이미 시도한 경로를 다시 실행한 사례는 없습니다. 출력·조건 결과와 선택한 Gooo 본문,
모델 입력 해시·점수·호출 기록을 압축 원본에 보관합니다.

이 자료는 [첫 학습 실험](../condition-candidate-20261010/README.md)의 절댓값 변형들입니다.
8개는 학습에 쓰였고, 나머지도 이미 평가에 소비한 표현·지역 변수 변형입니다. 24개를
새로운 독립 문제로 볼 수는 없습니다. 최대 4개 후보를 모두 확인하면 기본 탐색도
완성하므로, 이번 비교는 주로 **완성까지의 경로 수**와 관측 전달 동작을 보여줍니다.

## 시간과 메모리

피드백 방식의 실제 신경망 호출 28번은 중앙값 **8.583µs**, p95 **8.958µs**였습니다.
전체 72개 탐색 명령은 벽시계 **0.49초**, 프로세스 CPU는 사용자 **0.02초**와 시스템
**0.01초**, 최대 RSS는 **21,397,504바이트**였습니다. 전체 명령에는 모델·자료 읽기와
결과 파일 기록도 포함됩니다. 컴퓨터 전체 CPU 사용률의 증가량은 측정하지 않았습니다.

모든 자료의 탐색 구간 합계는 기본 방식 3.429ms, 첫 판단 방식 2.758ms, 피드백 방식
2.441ms였습니다. 반면 새 표현 묶음에서는 기본 0.451ms → 피드백 0.486ms,
표현·구조 동시 변경 묶음에서는 0.461ms → 0.480ms로 조금 늘었습니다. 원래 후보 검사가
작아서 판단·기록 비용도 영향을 줍니다. 고정 순서의 단일 실행이며 워밍업과 반복 측정을
통제한 벤치마크가 아니므로 이 시간으로 일반적인 속도 개선을 주장하지 않습니다.

원래 학습의 0.172초와는 별개 실행입니다. 이번 학습 호출과 native 실행 파일의 실행은
각각 **0회**입니다. 후보는 기존 typed interpreter로 검사했습니다.

## 구현과 원본

실행한 코드: `670f90582ec756ef8601d827fa188a474297b52b`의 깨끗한 체크아웃.
새 API의 [입력·제한·취소 처리](../../docs/condition-search.md)를 함께 볼 수 있습니다.
일반 Gooo CLI의 새 모델 제공자는 후속 연결 대상입니다.

- `protocol.txt`: 실행 전 정한 동일 예산과 비교 방식
- `report.json.gz`: 실제 72개 탐색과 판단·사례 기록; 원본 JSON과 압축 해제 바이트 비교 완료
- `process-time.txt`: 실제 전체 명령 비용
- `audit.json`: 원본 기록을 읽기만 해서 다시 센 결과
- `SHA256SUMS`: 공개 파일의 해시

```sh
cd studies/condition-search-20261010
shasum -a 256 -c SHA256SUMS
cd ../..
GOWORK=off GOTOOLCHAIN=go1.27.2 go run ./studies/condition-search-20261010 \
  studies/condition-search-20261010
```

재집계 명령은 모델 판단·코드 실행·학습을 추가로 하지 않습니다. 별도 실험을 만들 때는
`examples/condition-search`에 자료·모델·새 출력 폴더를 전달합니다.

# 직접 반환만 배운 작은 모델은 다른 표현도 조립할까

2026-10-10. Gooo 소스의 같은 값 흐름을 같은 입력으로 정리한 뒤, 작은 결정 모델을
새로 두 개 학습했습니다. 학습과 실행은 모두 로컬 Go CPU 코드입니다. 각 모델은
384→24→2, 매개변수 9,290개, FP32 가중치 37,160바이트입니다.

## 고정한 비교

[앞선 162개 소스 기록](../semantic-flow-normalization-20261010/README.md)을 그대로
사용했습니다. 학습에는 직접 반환 형태 16개만 넣었습니다. 같은 과제를 별칭·대입·복사로
쓴 64개, 새로운 상수를 쓴 다섯 형태의 80개, 적용 범위 밖 대조 소스 2개를 따로 집계합니다.
학습 설정은 둘 다 400회, 학습률 0.25, L2 0.0001, seed 17입니다.

v4와 v5를 각각 처음부터 학습했고, 앞선 공개 가중치나 실험을 다시 실행하지 않았습니다.
[계획](protocol.txt)은 결과를 보기 전에 커밋했습니다. 깨끗한 생산자는
`197790b77aab5f1190695e4e09c9b209d4ee0afb`, Go 1.27.2입니다.

## 첫 선택과 사례 완전성

모델이 후보를 고르면 바로 본문을 조립하고, 출력 8개와 조건 3개를 확인했습니다.
총 324개 선택의 본문과 모든 사례 결과를 남겼습니다.

| 범위 | v4: 전체 사례를 만족한 첫 선택 | v5: 전체 사례를 만족한 첫 선택 |
| --- | ---: | ---: |
| 학습에 쓴 직접 반환 |16/16 (100%)|10/16 (62.5%)|
| 같은 과제의 다른 표현 |32/64 (50%)|40/64 (62.5%)|
| 새로운 상수 |48/80 (60%)|50/80 (62.5%)|
| 적용 범위 밖 대조 소스 |2/2|1/2|

같은 과제의 다른 표현에서 출력 사례 완전성은 288/512 (56.25%)에서
344/512 (67.19%)로 늘었습니다. 조건 사례는 두 모델 모두 192/192였습니다.
비교 조건이 맞아도 잘못된 값을 반환할 수 있으므로 두 지표를 함께 읽어야 합니다.

동등한 표현 128쌍의 후보 확률 분포는 v5에서 모두 같았습니다. v4는 같은 쌍이 0개입니다.
이는 같은 입력을 받은 결정 모델의 일관성을 확인한 결과입니다. 같은 문제의 다른 표현은
학습 과제와 의미를 공유합니다. 새로운 종류의 프로그램에 대한 정답률은 여기서 측정하지 않았습니다.

v5는 표현 전이에서 나아졌지만 학습 사례와 중첩 분기 대조 사례에서 후퇴했습니다.
마지막 갱신 전 학습 손실도 v4 0.0410, v5 0.6111로 달랐습니다. 이번 실험에서는
설정을 바꾸거나 더 좋은 실행만 고르지 않았습니다. 입력 일관성 확보만으로 충분한
판단 품질이 따라오지는 않는다는 결과를 그대로 남깁니다.

## Gooo가 검사를 이어갔을 때

소스별 후보는 4개입니다. 기본 순서, 두 모델의 첫 순서, 두 모델의 실제 실패 피드백을
비교해 810회 탐색을 실행했습니다. 모두 162/162개 소스의 선언 사례를 마쳤습니다.

| 방식 | 전체 후보 시도 | 모델 호출 | 탐색 시간 합계 |
| --- | ---: | ---: | ---: |
| 모델 없음 |324|0|17.448 ms|
| v4 첫 판단 |226|162|22.109 ms|
| v4 실패 피드백 |226|226|27.566 ms|
| v5 첫 판단 |223|162|26.814 ms|
| v5 실패 피드백 |223|223|31.014 ms|

이미 검사한 후보를 다시 실행한 경우는 없었습니다. 피드백은 실제 실패를 다음 판단에
전달했지만 시도를 줄이지 못했습니다. 이번 모델은 첫 입력만 학습했으므로 피드백 결과는
그 제약 안에서 읽어야 합니다. 모델 없이도 이어가는 유한 탐색이 완성을 담당했습니다.
위 완성 비율은 소스에 적은 유한 사례 기준입니다.

평균 약 0.65개 코어의 명령 단위 사용량이며 PC 전체 CPU 상승분은 측정하지 않았습니다.
첫 선택과 탐색의 모델 호출은 합계 1,097회입니다. 네이티브 실행과 GPU 사용은 없습니다.
가중치는 FP32이며 이번 모델의 양자화 결과는 없습니다.

## 다음에 바꿀 부분

모델을 키우기 전에, 분기의 반환값이 비교의 어느 피연산자와 같은지 같은 명시적인
관계를 입력으로 주는 실험이 필요합니다. 지금 배열은 정확한 원자값을 보존하지만 작은
네트워크가 그 관계까지 배워야 합니다. 관계 입력이 도움이 되는지는 별도의 고정 비교로
확인할 계획입니다. 현재 학습 실패의 원인으로 단정하지 않습니다.

v5 가중치는 Go SDK의 `flowdecision.Decode`와 `SearchFlowBatches`에서 사용할 수 있습니다.
컴파일러 CLI의 v5 파일 연결은 후속 작업입니다. 현재 공개 컴파일러는 0.6.25이며,
이 실험 결과가 설치된 컴파일러에 자동으로 적용되지는 않습니다.
